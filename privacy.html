Política de privacidade

Atualização: 8 de novembro de 2026.

Finalidade

O Acer Backup Rclone é utilizado pelo proprietário para realizar e restaurar backups criptografados de um servidor Linux no Google Drive, por meio de Restic e Rclone.

Dados tratados

A autorização OAuth concede acesso limitado, de acordo com o escopo Google Drive autorizado, aos arquivos que o aplicativo cria ou abre. Os dados de backup são criptografados no servidor antes do envio. O Rclone mantém credenciais OAuth no ambiente privado do servidor para executar operações autorizadas.

Armazenamento e compartilhamento

Os arquivos criptografados ficam armazenados na conta Google Drive autorizada. O Google processa os dados conforme seus próprios termos e políticas. Este aplicativo não vende dados, não utiliza publicidade e não transfere voluntariamente arquivos a terceiros para fins comerciais. O GitHub Pages hospeda apenas estas páginas informativas, não os backups ou tokens.

Controle e exclusão

O proprietário pode revogar o acesso do aplicativo na segurança da conta Google, excluir os arquivos de backup no Drive e apagar a configuração OAuth local. A revogação impede novas operações autorizadas, mas não exclui automaticamente backups existentes.

Segurança

Os backups são criptografados pelo Restic. A recuperação depende da chave privada de criptografia mantida pelo proprietário. Nenhum sistema é isento de riscos.
